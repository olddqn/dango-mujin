# ADR-010 — Non-Technical Objection Path Operations

- **Status:** Proposed（運用設計。Phase C 公開の前提条件。ADR-006 D6-9 と同じく当事者参加経路の保証つき交渉を経て Accepted となる）
- **Date:** 2026-06-13
- **Context source:** Mujin Constitution 第10・11・12・29条（[`docs/MUJIN_MASTER_PLAN_V1.md`](../MUJIN_MASTER_PLAN_V1.md) §3）, ADR-005 D-1, ADR-006 D6-5/D6-7, [`docs/MUJIN_MVP_SPEC.md`](../MUJIN_MVP_SPEC.md) §15, Gap Analysis MI-1/X-3, MQ-14
- **Related:** ADR-005（D-1 の母体）, ADR-006（不可侵条項としての異議権）, ADR-001（append-only 記録）, ADR-002（境界——異議経路は第三経路）

## Context

ADR-005 D-1 と憲法第10〜12条は「異議は権利であり、Dan-Go 参加能力・技術アクセスなしに行使できる」ことを確定した。ADR-006 はこれを**不可侵条項**に格上げした。しかし権利は経路がなければ存在しない。現状:

- Phase A 実装の `record_objection` は `phone / in_person / transcribed / third_party` チャネルを**データとして表現できる**が、それらのチャネルを**実際に運用する制度**（誰が電話を取るか、誰が書き起こすか、誰が握り潰しを監査するか）は存在しない。
- MVP §15.3 は「UI を経由しない非技術経路を最低1つ」を完成条件としたが、具体形態を OQ-12 として未決のまま残した。
- Master Plan の自己レビューと ADR-006 の自己レビューの両方が、本 ADR を Phase C 公開の前提として指名した（「UI だけ先行させない」撤退基準）。

異議経路の運用設計は、**最も異議を必要とする人が最も異議を出しにくい**という構造的非対称（識字・言語・接続・恐怖）の中で設計されなければならない。異議経路自体が Reach Gap を再生産するなら、それは第22・23条への違反である。

---

## 検討 — 異議提出経路の比較

| 経路 | 到達性 | 匿名性 | 記録忠実性 | 報復リスク | 運用コスト | 採否 |
|---|---|---|---|---|---|---|
| **Web フォーム** | 低（技術・識字・言語前提） | 高（設計次第） | 高（本人の言葉がそのまま残る） | 低 | 低 | 採用（ただし既定にしない——これだけでは第11条違反） |
| **Email** | 低〜中 | 中 | 高 | 中（アドレスが特定子になる） | 低 | 採用 |
| **電話** | **高**（最重要経路。識字不要・広く普及） | 中（番号は秘匿可能） | 中（書き起こしを要する） | 中 | 中（受理時間帯・多言語対応） | **採用・中核** |
| **SMS** | 高（通話より心理的障壁が低い） | 中 | 高（本人の文字が残る） | 中 | 低 | 採用 |
| **音声メッセージ** | 高（時間帯の制約なし・識字不要） | 中 | 高（本人の声がそのまま証跡） | 中 | 低〜中 | 採用（電話の留守録形態として一体運用） |
| **対面** | 中（場所に依存するが、最も信頼が成立しやすい） | 低 | 中（受理者の記録に依存） | **高**（目撃される） | 高 | 採用（既存の現場接点——NPO 窓口・コミュニティ拠点——に相乗りし、専用窓口を作らない） |
| **代理人** | 高（本人が動けない場合の唯一の経路になりうる） | 中 | 低〜中（**代理人による変形リスク**） | 中 | 低 | 採用（D10-8 の制約つき） |
| **翻訳者経由** | 高（言語障壁の解消） | 中 | 低〜中（**翻訳による変形リスク**） | 中 | 中 | 採用（D10-9 の制約つき） |
| **NPO 経由** | 高（既存の信頼関係に載る） | 低 | 中 | **構造的に高**（**異議の対象が NPO 自身である場合、経路が利益相反する**） | 低 | 条件付き採用（**NPO への異議は NPO 経由以外の経路が常に並存することを条件とする**） |

**結論:** 単一の正解経路は存在しない。**複数経路の並存自体が設計である**——どの経路にも構造的弱点があり、弱点は経路ごとに異なるため、並存だけが「すべての当事者に少なくとも1つの使える経路」を近似できる。

## Decision

### D10-1. 最低経路保証（Minimum Path Guarantee）

Mujin が公開運用される（Phase C 以降）すべての期間・地域において、以下の3系統を**常時並存**させる:

1. **音声系**: 電話＋音声メッセージ（識字不要・技術最小）。
2. **文字系**: SMS / Email / Web フォーム（本人の言葉が無変形で残る）。
3. **対人系**: 対面（既存の現場接点に相乗り）＋代理人＋翻訳者経由。

いずれかの系統が運用不能になった場合、**Phase C の撤退基準が発動**する（新規ケースの公開受付を停止し、経路復旧を優先する）。UI（Web フォーム）は3系統の1つの、さらに一部でしかない——**Web フォームだけの状態は「異議経路がある」と見なされない**。

### D10-2. Objection Steward（異議受理人）の新設

異議の受理は **Objection Steward** という新設の役割が担う。

- Steward は **Mujin 運営から機能的に独立**する: 運営者は Steward を解任できない（解任は Dan-Go 交渉事項）。Steward の予算は Treasury 上で運営予算と分離して公示される。
- Steward は**人間**である。Translation Agent 等の AI は記録・翻訳の**補助**に限定され、受理・対応の判断を行わない（第20条）。
- Steward は記録上特定可能である（第20条: 匿名の権力を作らない——受理の握り潰しを個人に遡れるようにする）。
- NPO・支援者・資金提供者は Steward を兼任できない（利益相反の構造的排除）。
- 候補としての「Mujin 運営」「NPO」「第三者監査人」は受理者としては**不採用**: 運営と NPO は異議の対象になりうるため受理者になれない。第三者監査人は受理ではなく**監査**（D10-5）に置く——受理と監査の分離。

### D10-3. 受理と記録の分離

**異議を受理する人（Steward）と、異議を正式記録に転記する人（Recorder）を分離する。**

- Recorder は受理された異議を append-only の異議記録（Phase A の `objections.jsonl` 系統）に転記する。転記時、**本人の言葉（音声・原文）への参照を必ず保持**し、要約・言い換えのみの記録を禁止する。
- 分離の目的: (1) 受理者が「記録しない」ことで異議を消す単独権限を持たない、(2) 転記の正確性を受理者の利害から切り離す。
- 当事者は自分の異議の記録を確認・訂正できる（訂正は append-only、第13条）。確認手段も非技術経路で提供される（電話で読み上げ確認、等）。

### D10-4. 翻訳の忠実性保証

- 異議の翻訳では**全文訳を原則**とし、要約翻訳を禁止する（MVP の Translation Agent 境界「同意場面では全文訳」を異議場面に拡張）。
- **原語の記録を常に保持**する。翻訳は原語記録への注釈であり、置換ではない。争いが生じた場合、原語が優先する。
- 重要な異議（不可侵条項への違反申立て等）では**二重翻訳**（独立した2訳の照合）を行う。Translation Agent は2訳の差分の指摘に使ってよい（差分の解消判断は人間）。
- 翻訳者は異議の内容について守秘義務を負い、翻訳で知った情報を異議対応以外に使用しない。

### D10-5. 監査 — 異議が握り潰されない仕組み

- **全数突合**: 受理番号は受理時に当事者へ即時発行される（電話なら口頭で短い番号を伝える）。監査人は「発行された受理番号の総数」と「記録された異議の総数」を定期的に突合する。**欠番は握り潰しの一次指標**である。
- **対応期限の公開**: 各異議は受理から一定期限内に「対応・対応不能の理由・対応中」のいずれかの状態を持たねばならず、状態の分布（個人参照なし）は構造指標として公開される（第14条）。無応答は不作為として監査対象。
- 監査人は Steward からも運営からも独立し、Dan-Go 交渉で指名される。監査報告は Dan-Go に公開で提出される——**Mujin の内部に閉じない**。
- 当事者は自分の異議の状態を、受理番号だけで（ID・ログイン不要、電話でも）照会できる。

### D10-6. 識字・接続・知識の障壁への対応

| 障壁 | 対応 |
|---|---|
| **識字できない** | 音声系（D10-1-1）が完全な代替になる。文書での通知が必要な場面はすべて音声読み上げの選択肢を持つ。識字状態は記録されない（属性収集の禁止、§5.3 Identity Layer） |
| **インターネットにアクセスできない** | 電話・SMS・対面・代理人で全手続き（提出・確認・訂正・状態照会）が完結する。**オンライン手続きにしか存在しない操作を作らない**ことを設計規則とする |
| **GitHub / Dan-Go を知らない** | 異議の行使に Dan-Go の知識・アカウント・Claim 言語化能力は一切不要(D-1 の原義)。Steward が異議を受理した時点で、Dan-Go 側への接続(必要なら Claim 化)は**受理側の義務**であり当事者の義務ではない。当事者に「正しい窓口」を探させない——**どの経路に届いた異議も有効**(no wrong door 原則) |

### D10-7. 報復リスクへの対応

- **異議の存在自体の秘匿選択**: 当事者は異議を「対象に知らせて対応を求める」「対象に知らせず記録だけ残す（パターン監査の材料にする）」から選べる。後者は即時対応を生まないが、報復の恐怖の下でも記録を残す道を保証する。
- 異議者の身元は、対応に必要な最小範囲を超えて対象（NPO・支援者・運営）に開示されない。
- **報復の推定**: 異議提出後の一定期間に当事者への支援縮小・関係悪化が観測された場合、因果の立証責任を当事者に置かず、対象側が非報復の説明責任を負う（第10条「不利に作用しない」の運用化）。
- 報復が認定された場合、それ自体が最も重い憲法違反（第10条＋不可侵条項）として道義的レビュー（第15条・ADR-008 候補）の対象となる。

### D10-8. 代理人制度の制約

- 代理提出には**本人の意思の確認可能性**を要する: 代理人は「本人がこの異議を望んでいる」ことを示す手がかり（本人の音声・本人との接点の説明）を添える。確認不能な代理異議は「第三者報告」として別系統に記録され、本人の異議としては扱わない（本人の名で語る権限を勝手に作らない）。
- 代理人は異議の取り下げ・内容変更を**単独でできない**（提出はできるが、撤回は本人確認を要する——代理人が本人の異議を握る構造を防ぐ）。
- 同意延期状態（憲法第7条）の当事者について: 本人意思の確認が構造的に不可能な間は、代理異議は常に「第三者報告」系統として記録し、本人が同意可能になった時点で本人異議への昇格を本人に確認する（ADR-003 の昇格ゲートと同型の構造）。
- 代理人の継続的独占の禁止: 特定の代理人だけが特定の当事者の声の唯一の経路になっている状態を等価性監査の観測対象とする。

### D10-9. 翻訳者制度の制約

- D10-4 の忠実性保証に加えて: 翻訳者は当事者の選任を優先する（当事者が信頼する翻訳者を連れてくる権利）。Mujin 側が手配する場合、**異議の対象と利害関係のない翻訳者**を選ぶ。
- 翻訳者は異議の内容への意見・助言を翻訳に混入させない。助言が必要な場合は翻訳者としてではなく、明示的に別の役割（支援者）として、本人の求めに応じてのみ行う。
- 機械翻訳（Translation Agent）は下訳・差分検出に使用できるが、異議の正式翻訳の最終責任は常に人間の翻訳者が負う。

### D10-10. 公開範囲の三層

| 層 | 内容 | 対象 |
|---|---|---|
| **公開** | 異議の件数・対象種別・状態分布・対応期限遵守率・経路別利用率（すべて個人参照なしの構造指標） | 全員（`/transparency`・Dan-Go への監査報告） |
| **限定公開** | 異議の内容（個人特定情報を除去・本人の公開同意がある場合のみ）。対応の経緯 | 対応に関与する Steward・Recorder・監査人・（本人が望む場合）Dan-Go 交渉 |
| **非公開** | 異議者の身元。秘匿選択された異議の存在。報復リスク評価 | Steward と監査人のみ。**運営者は非公開層にアクセスできない**(運営者が異議の対象になりうるため) |

既定は**非公開**であり、公開は本人の明示的選択によってのみ上の層へ移る。透明性の非対称原則（Master Plan §10.2: 権力に透明・弱さに不透明）をここでも適用する——**異議の統計は最大限公開し、異議者は最大限保護する**。

### D10-11. Reach Gap との関係（経路自体の限界の明示）

本 ADR の経路群もまた、到達できない人々を持つ: 電話を持たない人、代理人も翻訳者も持たない人、異議という行為自体を知らされていない人、報復の恐怖が秘匿経路すら使わせない人。

- **本 ADR は異議の Reach Gap を解決したと主張しない。**
- 経路別利用率の監査（D10-5）は「使われていない経路」と「届いていない層」の観測材料であり、その解釈は Dan-Go 交渉に開かれる（定義の非所有、第22条）。
- 異議経路の存在は、登録時・支援開始時・同意確認時のすべてで、本人の言語で、非文字手段を含めて告知される——**知らされていない権利は権利ではない**。ただし告知の完全性もまた保証できないことを、ここに明記する。

## Consequences

### 正
- 憲法第10〜12条が紙の上の権利から運用可能な権利になり、Phase C 公開の前提が満たせる。
- 受理（Steward）・記録（Recorder）・監査（独立監査人）の三権分離により、単独主体による握り潰しが構造的に困難になる。
- ADR-006 D6-9 の自己言及デッドロック（憲法採択に当事者参加経路が必要）に対し、本 ADR の経路群が採択交渉の参加経路としても機能する。

### 負 / 要対応
- **運用コストが恒常的に発生する**（自己レビュー③参照）。多言語電話受理は本 ADR で最も高価な約束であり、資金が枯れたときに最初に削られる圧力を受ける——削られた場合 Phase C 撤退基準が発動する設計だが、その執行自体が運営の自制に依存する。
- Steward・Recorder・監査人という3つの人的役割の確保が前提になる。小規模な立ち上げ期には兼任圧力が生じる（自己レビュー②参照）。
- 「第三者報告」系統・受理番号・状態照会は Phase A データ層の拡張を要する（実装は本 ADR の範囲外。Phase C 実装時の要件として記録）。

## Non-decisions
- Steward・監査人の最初の選任方法（Dan-Go 交渉事項。本 ADR は資格要件と独立性のみ確定）。
- 対応期限の具体値（運用開始時に当事者参加の下で設定し、構造指標で見直す）。
- 報復認定後の救済・補償の内容（ADR-008 候補: Moral Accountability Procedure に委譲）。
- 異議経路の多言語対応の言語リスト（対象コミュニティ確定（MQ-12）後に決まる）。

## Relationship to ADR-001〜006
- **ADR-001**: 異議記録は append-only 原則（正典の思想）を継承。Phase A の `objections.jsonl` 系統が記録基盤。矛盾なし。
- **ADR-002**: 異議経路はデータ境界の外の第三経路（MVP §3.2 図示済み）として疎結合を保つ。Dan-Go への接続義務（D10-6）は当事者ではなく受理側が負う形で境界を侵さない。矛盾なし。
- **ADR-003**: 代理異議の本人昇格（D10-8）は昇格ゲートと同型——確認なき代理は本人の名を使えない。整合。
- **ADR-005**: D-1 の直接の運用化。「不利に作用しない」を報復の推定（D10-7）として強化。整合。
- **ADR-006**: 不可侵条項（異議権）の実効性を供給する。D6-9 の採択交渉の参加経路を提供する依存関係（自己レビュー④参照）。
