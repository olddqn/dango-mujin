# ADR-006 — Mujin Constitution Adoption

- **Status:** Proposed（Dan-Go 公開交渉への提案。第29条の性質上、本 ADR は設計者単独では Accepted にできない——§Decision D6-8 参照）
- **Date:** 2026-06-13
- **Context source:** [`docs/MUJIN_MASTER_PLAN_V1.md`](../MUJIN_MASTER_PLAN_V1.md) §3（Mujin Constitution 30条）, [`docs/MUJIN_MVP_SPEC_GAP_ANALYSIS.md`](../MUJIN_MVP_SPEC_GAP_ANALYSIS.md) §0（来歴問題）, `mujin_reflections_from_saiyan_scouter.md`（Mujin Safety Constitution 8項目＋追加提案9–13）
- **Related:** ADR-001（正典）, ADR-002（境界）, ADR-003（昇格）, ADR-004（貢献）, ADR-005（当事者尊厳）

---

## Context

Master Plan v1.0 §3 は Mujin Constitution 全30条を起草した。しかし起草は採択ではない。現状、Mujin の規範体系は4層に分裂している:

1. **ADR-001〜005** — 確定済みの個別決定（正典・境界・昇格・貢献・尊厳10原則）。
2. **MVP v1.1 統一不変条件** — A群8項目＋B群（ADR-005 D-1〜10）。
3. **Mujin Safety Constitution（8項目）** — REFL（mujin_reflections）が「現行」と前提するが、**原典がリポジトリに存在しない**（Gap §0 / MVP OQ-9 / Master Plan MQ-13）。REFL はこれへの追加提案9–13 を行っている。
4. **Mujin Constitution 30条** — Master Plan §3 の起草。上記すべてを統合する意図を持つが、採択手続きが未定義。

この分裂を放置すると: どの規範が優越するか不明になり、実装（Phase C 以降）が参照すべき正典を持たず、「憲法が二重化する」（Master Plan 自己レビューの警告）。本 ADR は採択の手続き・優先順位・継承関係・改正手続きを確定する。

---

## Decision

### D6-1. 採択対象と正典化

**Master Plan v1.0 §3 の Mujin Constitution 全30条を、Mujin の最高規範として採択する。** 採択後、本憲法は唯一の憲法的正典であり、他のすべての規範文書（ADR・SPEC・README・実装）はこれに従属する。

### D6-2. ADR-001〜005 との優先順位

**優先順位（上が優越）:**

```
1. Mujin Constitution（30条）          — 最高規範
2. ADR-005（当事者尊厳 D-1〜10）       — 憲法の直接の母体。憲法と一体として解釈
3. ADR-001〜004（正典・境界・昇格・貢献）— 憲法に従属する技術的決定
4. MUJIN_MVP_SPEC v1.1                 — 仕様
5. 実装・運用文書
```

- **遡及整合の確認:** ADR-001〜005 と憲法30条の間に矛盾は確認されていない（本 ADR 自己レビューで検証）。憲法は ADR-005 の D-1〜10 をほぼ全条文化し（第2・5・7・8・10・11・21・22・23・26条等）、ADR-001〜004 の技術的決定（正典 JSONL・READ/WRITE 境界・昇格ゲート・Contribution 統合）は第13・14条（append-only・公開監査）の下で有効に存続する。
- **衝突時の規則:** 将来、ADR と憲法が衝突した場合、憲法が優越し、当該 ADR は改訂対象となる。ただし衝突の「発見」自体を Dan-Go の Claim として公開する（静かな上書きをしない）。

### D6-3. Mujin Safety Constitution（8項目）との継承関係

- REFL が前提する Mujin Safety Constitution（8項目）の**原典は不在**である。本 ADR は不在を隠さない。
- **継承宣言:** 30条憲法は、REFL から判読できる8項目の趣旨（支援者の権力制限〔→第17・18・25条〕・透明性レポート〔→第14条〕）および追加提案9–13（自己申請バイアスの監査〔→第16条〕・成功指標の多様性〔→第26条〕・失敗の尊厳〔→第5条〕・外部共助への敬意〔→第21条〕・当事者による評価権〔→第10–12条〕）を**包摂的に継承**する。
- **新旧関係:** 30条憲法の採択をもって、「Mujin Safety Constitution」という名の独立規範は**30条に統合され、独立の規範としては存続しない**。ただし原典が将来発見・復元された場合、30条との差分を Dan-Go 交渉で照合する（差分があれば改憲論点になる——隠さない）。
- 8項目原典の探索・復元は引き続き Open Question（MQ-13）として残す。

### D6-4. Dan-Go との境界

- 本憲法は **Mujin を拘束する。Dan-Go を拘束しない。** Dan-Go は自らの憲法（Art.1/3/5/7/10 等）を持ち、Mujin 憲法はそれと**整合するが従属も支配もしない**（思想的に不可分・実装的に疎結合——ADR-002 の規範版）。
- 両憲法の整合点は条文上明示されている（第14条 ← Dan-Go Art.5、第18条 ← Art.7 の継承と制限、第29条 ← Art.3 の交渉原則）。
- **境界規則:** Mujin 憲法の条文が Dan-Go の構造変更を要求することはできない。要求がある場合、それは Mujin 憲法の条文ではなく **Dan-Go への Claim** として提起される。
- Dan-Go 憲法と Mujin 憲法が矛盾する事案が生じた場合（例: Art.7「評判は貢献から生まれる」と第18条「実績の非権威化」の解釈衝突）、**当事者保護に厚い方の解釈**を採り、衝突自体を公開交渉に付す。

### D6-5. 改憲手続き（第29条の具体化）

第29条を以下の手続きとして確定する:

1. **発議:** 誰でも改憲 Claim を Dan-Go に提起できる（Art.3 継承。当事者・支援者・運営者・外部の別を問わない）。
2. **公開交渉:** Dan-Go の公開交渉を経る。交渉には**直接的当事者（支援を受ける側）の声が参加する経路の保証**が必須——技術アクセス不要・翻訳保証・参加による不利益の禁止（Master Plan §4.4）。この経路保証がない交渉での「合意」は無効。
3. **不可侵条項の特別手続き:** D6-7 に定める不可侵条項の改正には、通常の交渉に加え、**当該権利の保持者（当事者）側からの発議または明示的賛成**を要する。権利を制限する改正を、権利者の頭越しに行うことはできない。
4. **記録:** 改憲の全過程は append-only で記録される（第13条は改憲手続き自体にも適用される）。
5. **凍結期間:** 採択から最初の実運用（Phase C 公開）までの間は、運用実績なき机上の改憲を避けるため、字句修正を除く改憲発議を凍結する。ただし**当事者からの発議はこの凍結の例外**とする（当事者の声を待たせない）。

### D6-6. Agent は憲法を変更できるか

**できない。全面的に、例外なく、できない。**

- AI Agent は改憲の発議・交渉参加・採決・解釈確定のいずれの主体にもなれない（第20条「AI は判断しない」の憲法レベルへの適用）。
- Agent ができるのは: 憲法違反パターンの**検出と人間への警告**（Transparency Agent の役割、Master Plan §11.2）、改憲交渉の**記録・翻訳・整理の補助**まで。
- Agent の出力が事実上の改憲（運用による空文化）にならないよう、Agent 動作と憲法条文の乖離は等価性監査と同様に公開監査の対象とする。
- 本決定自体（D6-6）は**改正不能のメタ条項**とする: 「Agent に改憲権を与える改憲」は、本 ADR の下で受理されない。

### D6-7. 不可侵条項（objection 権・consent 権の不可侵性）

以下を**不可侵条項**として指定する。不可侵条項は D6-5-3 の特別手続きによってのみ改正でき、かつ**権利を縮小する方向の改正は受理されない**（拡張のみ可能）:

| 不可侵条項 | 対象条文 | 不可侵の理由 |
|---|---|---|
| **異議権（objection）** | 第10・11・12条 | 異議権は他のすべての権利の実効性の前提である。異議できないシステムでは、他のどの条文の違反も当事者から指摘できない。**異議権を縮小する改憲は、改憲手続き自体への異議を封じるため、論理的に自己破壊的である** |
| **同意権（consent）** | 第6・7・8・9条 | 同意なき参加は参加ではなく包摂的暴力である。同意権の縮小は「同意できない状態は同意ではない」（第7条）の否定であり、Mujin の存在理由を消す |
| **撤回・非登録の尊厳** | 第1・2条 | 出口の自由がない入口は罠である |
| **人間価値の非計測** | 第4条 | これが破られた瞬間、Saiyan Scouter v1 の失敗（支援が最も必要な人が最も低く評価される逆説）が再演される |
| **AI 非判断** | 第20条＋D6-6 | 上記すべての違反が「効率化」の名で AI に委任されることを防ぐ最後の防壁 |

### D6-8. Reach Gap を憲法に含めるべきか

**含める。ただし「解決の約束」としてではなく「未解決の保存」として。**

- 第22条（定義の非所有）・第23条（解決の不主張）は維持する。これは Reach Gap を「憲法が解決する」のではなく、**「憲法が忘れることを禁じる」**構造である。
- 根拠: claim-saiyan-scouter-001 §9 ——「この Claim が一度も議論されないまま忘れられることは、Dan-Go 自体の誠実さへの問いになる。Reach Gap という問いを持ちながら対話しないことは、Art.10（尊厳を侵害するな）の別形態の違反である可能性がある」。忘却の禁止は尊厳条項の一部であり、憲法に置く場所がある。
- **含めない範囲:** Reach Gap の定義・観測方法・応答方針は憲法に書かない（それらは交渉対象であり、憲法に書けば定義の所有=第22条違反になる）。

### D6-9. 採択の手続き（本 ADR 自身の地位）

第29条の論理は本 ADR 自身に適用される: **設計者だけの合意による採択は、設計者だけの合意による改正と同様に無効である。** よって:

- 本 ADR は **Proposed** として登録され、Dan-Go の公開交渉（当事者参加経路の保証つき）を経てのみ Accepted となる。
- 交渉までの暫定期間、実装は ADR-001〜005＋MVP v1.1 統一不変条件（既に Accepted）を正典として継続する。30条はこの期間「拘束力ある草案」として実装の参照先になるが、ADR-005 と衝突する解釈はできない（衝突がないことは検証済みだが、解釈の階層を明確にしておく）。
- claim-saiyan-scouter-001 の条件付き賛成の論理を借りる: **直接的当事者の声が交渉に参加する経路が設計されないまま、設計者だけの議論として本憲法が固定化される場合——本憲法の正統性は認められない。**

## Consequences

### 正
- 4層に分裂していた規範体系が単一の優先順位に整理される。
- 異議権・同意権が「条文」から「不可侵条項」へ格上げされ、将来の運営者・多数派・効率化圧力から構造的に保護される。
- Agent の改憲不能が確定し、AI 権威化リスク（Master Plan RA-4）の最終防壁が置かれる。
- 「Mujin Safety Constitution」の来歴問題が、隠蔽ではなく明示的な包摂継承として処理される。

### 負 / 要対応
- 採択が Dan-Go 公開交渉に依存するため、**交渉が行われない限り憲法は Proposed のまま**である。これは欠陥ではなく設計（正統性は手続きから来る）だが、実装スケジュール（Phase C）が交渉の遅延に影響され得る。
- 当事者参加経路の保証（D6-5-2）は、非技術異議経路（ADR-010 候補）と同じ運用課題を持つ——**経路の保証なしに交渉を開けば本 ADR 自身が無効**という自己言及的な厳しさがある。
- 不可侵条項の「拡張のみ可能」は、誤って過剰に広い権利を入れた場合に修正不能になるリスクを持つ（自己レビュー②参照）。

## Non-decisions
- 30条の条文内容の変更（本 ADR は採択手続きの確定であり、条文の再起草はしない）。
- Mujin Safety Constitution 原典の探索方法（MQ-13 のまま残す）。
- 当事者参加経路の具体的運用（ADR-010 候補に委譲）。
- 道義的責任の帰属・救済手続き（第15条の運用、ADR-008 候補に委譲）。
- 法人格・法域の選択（MQ-19、ADR-007 候補に委譲）。

## Relationship to ADR-001〜005
- **ADR-005** — 憲法の直接の母体。D-1〜10 は第1〜3章・第21〜23・26条に条文化済み。優先順位上、憲法と一体として解釈される（D6-2）。矛盾なし。
- **ADR-001** — 正典 JSONL・append-only は第13条の具体例として存続。human review の道義的責任化（第15条）は ADR-001 の `requires_human_review` の解釈を深めるのみ。矛盾なし。
- **ADR-002** — 疎結合境界は D6-4 で規範レベルに拡張（憲法は Dan-Go を拘束しない）。矛盾なし。
- **ADR-003** — 昇格ゲートは第7条（同意延期）・第8条（発見経緯）の運用形。矛盾なし。
- **ADR-004** — Contribution 統合・スコア/債務排除は第3・4・18・25条と一致。矛盾なし。
