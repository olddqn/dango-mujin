# ADR-008 — Moral Accountability Procedure

- **Status:** Proposed（制度設計。ADR-006/010 と同じく当事者参加経路の保証つき Dan-Go 交渉を経て Accepted となる）
- **Date:** 2026-06-13
- **Context source:** Mujin Constitution 第15条（advisory は道義的免責ではない）・第5条（失敗の非帰属）・第10条（異議は権利）, ADR-005 D-4/D-10, claim-saiyan-scouter-001 論点10（善意の害悪への責任）, Master Plan MQ-10 / RA-7, ADR-010 自己レビュー⑤-4（報復認定後の救済が空のままでは D10-7 が威嚇力を持たない）
- **Related:** ADR-005（D-4 の母体）, ADR-006（第15条の憲法化）, ADR-010（異議経路——本 ADR の入口）

---

## Context

ADR-010 により異議は**届く**ようになった。しかし届いた先が空洞なら、異議経路は当事者の労力と希望を吸い込む装置にしかならない。現状未定義なのは:

- 異議が**正当と認められた**とき、何が起きるのか。
- 「説明できない接触」「同意違反」「撤回要求の無視」「報復」が発生したとき、誰が・何を・どう負うのか。
- claim-saiyan-scouter-001 論点10 の核心: **「接続 → 支援 → 失敗」の連鎖が生じた場合、設計者の道義的責任が残る。「advisory only」という免責は技術的なものであり、道義的責任を免除しない。** ——この命題は ADR-005 D-4 と憲法第15条で「責任は存在する」と確定したが、**帰属・手続き・救済は意図的に未決のまま**だった（ADR-005 Non-decisions）。

本 ADR はその空白を埋める。ただし埋め方自体が危険を持つ: 責任制度は容易に**新しい裁判所・新しい権力**になる。本 ADR は「処罰の制度」ではなく**「直視の制度」**として設計する。

## 検討 — 道義的責任とは何か

### 法的責任との違い

| | 法的責任 | 道義的責任（本 ADR の対象） |
|---|---|---|
| 根拠 | 法令・契約 | Mujin 憲法と、接続を設計した者の引き受け |
| 判定者 | 裁判所・行政 | 本 ADR のレビュー機構（処罰機関ではない） |
| 帰結 | 賠償・刑罰・行政処分 | 直視・説明・修正・停止・再発防止（D8-7） |
| 免責 | 法的免責は可能（advisory 条項等） | **免責は存在しない**（第15条）。引き受けの放棄だけが存在し、それは記録される |
| 時効 | あり | なし（append-only の記録は消えない） |

道義的責任とは: **自らの設計・行動が他者の現実に作用した事実から目を逸らさない義務**である。賠償能力・違法性・故意の有無に依存しない。「私たちの接続がなければこの害悪はなかったかもしれない」という反実仮想を、制度として保持し続けることである。

### advisory_only はなぜ免責にならないのか

1. **作用の実在**: advisory な提示も人の行動を変える。「推奨ではなく情報提供です」と言いながら情報の選択・順序・タイミングを設計した者は、その作用の設計者である。
2. **非対称の実在**: Mujin と当事者の間には情報・資源・選択肢の非対称がある。非対称の下では「参考意見」は事実上の指示として機能しうる。
3. **設計の選択性**: 何を advisory として提示し、何を提示しないかは選択であり、選択には選択者がいる。
4. claim-saiyan-scouter-001 の言葉を借りれば: 免責条項は**技術的**なものである。技術的免責は法的リスクを下げるが、**目を逸らす権利**を誰にも与えない。

## Decision

### D8-1. 手続きの性格 — 処罰ではなく直視

道義的レビューは**処罰機関ではない**。その目的は: (1) 何が起きたかの誠実な確定、(2) 当事者への応答、(3) 構造の修正、(4) 記録による再発防止。**個人への制裁の executor にならない**——制裁的措置（役割の停止等）は再発防止に必要な範囲でのみ、構造的措置として行う。これは第5条（失敗の非帰属）の運営側への適用でもある: **当事者の失敗を構造に帰属させる原則は、運営側の失敗を個人の悪意だけに帰属させない原則と対である**（悪意の個人を構造が匿うことも、構造の欠陥を個人に押し付けることも、両方を拒否する）。

### D8-2. トリガー（レビューが開始される事由）

以下のいずれかで道義的レビューが開始される。**開始の拒否はできない**（受理されたトリガーは必ずレビュー記録を生む——「レビューしない」という決定すら記録される）:

| トリガー | 入口 |
|---|---|
| T1: 異議が Steward 受理後の確認で正当性の疑いを持つ場合 | ADR-010 経路 |
| T2: **説明できない接触**の発生（「なぜあなたに接触したのか」に answer できない事案） | 異議・監査・自己申告 |
| T3: **同意違反**（同意なき公開・同意範囲外のデータ使用・同意延期中の接触・確認義務の不履行） | 異議・監査・自己申告 |
| T4: **撤回要求の無視**（withdrawn 後の公開継続・データ利用・接触） | 異議・監査 |
| T5: **報復**の推定（ADR-010 D10-7 ——異議後の支援縮小等で対象側が非報復を説明できない場合） | 監査 |
| T6: Reality Feedback 上の害悪の観測（`dignity_violation_detected` 等） | ADR-001 正典・Phase 27 Bridge |
| T7: 運営者・Steward・Agent 運用者の**自己申告**（自分たちの誤りの自己開示。これを不利に扱わない——自己申告を罰する制度は隠蔽を育てる） | 内部 |

### D8-3. レビュー主体 — Accountability Panel（三者構成）

レビューは単独主体に委ねない。**Accountability Panel** を事案ごとに構成する:

1. **独立監査人**（ADR-010 D10-5 の監査人と同系統。事案の利害関係者を除く）— 事実確定の主導。
2. **当事者代表** — 影響を受けた当事者本人、または本人が指名する代理（D10-8 の制約準用）。本人が参加を望まない場合は不参加の自由を保証し、**不参加が当事者に不利に解釈されることを禁止**する。
3. **Steward**（受理経路の継続性のため。ただし Steward 自身が対象の事案では除斥）。

- **不採用の候補**: Mujin 運営（自己審査になる）・NPO（利益相反——ただし事実関係の参考人にはなる）。
- **Dan-Go 公開交渉の位置**: Panel の上訴先・最終審であり、一次レビュー主体ではない（すべてを公開交渉に投げると、当事者の保護（非公開層）と交渉の負荷が両立しない）。Panel の結論に当事者または対象が不服の場合、Dan-Go Claim として公開交渉へ上げる経路を保証する。
- 除斥規則: 事案の対象・対象の利害関係者は Panel に入れない。全 Panel 構成は記録上特定可能（第20条）。

### D8-4. 責任の帰属 — 複合帰属の原則

責任は「個人 / 組織 / Agent」の択一ではなく**複合的に帰属**させ、各層の取り分を明示する:

| 層 | 帰属の内容 |
|---|---|
| **構造（設計）** | その害悪を可能にした設計・規則・不在の欠陥。**最初に検討される層**（第5条の対応原則: 構造から先に問う） |
| **組織（運営・NPO）** | 監督・資源配分・是正機会の不行使 |
| **個人（判断者）** | 第20条により判断は特定可能な人間が行っている。その判断の道義的引き受け。ただし**構造の欠陥を個人に押し付ける身代わりを禁止**する |
| **Agent（の運用者）** | D8-5 参照 |

複合帰属の出力は「誰々が悪い」ではなく「**この害悪は、この設計の下で、この組織の監督の中で、この人の判断と、この Agent の出力が重なって生じた**」という重層的な記述である。

### D8-5. Agent 責任 — Agent は責任を負えない。だから運用者が負う

- AI Agent は道義的責任の主体になれない（謝罪も引き受けも直視もできない——責任の文法の外にいる）。**よって Agent の誤った提案・出力に起因する害悪の責任は、(1) Agent を設計・承認した者、(2) その出力を human review で追認した者、(3) review 体制を設計した構造——に複合帰属する**。
- 「AI がそう言ったから」は責任の終点ではなく**起点**である（第20条の責任版）。
- 追認のゴム印化（review が形骸化して Agent 出力を素通しする状態, Master Plan RA-4）が事案の背景にある場合、それは個人の怠慢ではなく**構造の欠陥として**先に帰属される（D8-4）。
- Agent 自体への措置: 出力の停止・再設計・廃止（第28条/第30条)。これは処罰ではなく構造修正である。

### D8-6. 事由別の標準応答

| 事由 | 標準応答（D8-7 の救済手段から構成） |
|---|---|
| **説明できない接触**（T2） | 即時: 当該接触様式の停止。当事者への説明と謝罪（本人が望む場合のみ——望まない当事者に謝罪を受け取る義務を課さない）。構造: 接触根拠の文書化義務（exporter の `outreach_explanation_required` 系）の強化。**説明できない接触が反復する経路は、経路ごと停止する** |
| **同意違反**（T3） | 即時: 違反状態の解消（公開停止・データ利用停止）。本人への通知と訂正記録。構造: 同意ゲートの欠陥審査。違反が「効率のための省略」に由来する場合、省略を可能にした規則・圧力を記録する |
| **撤回要求の無視**（T4） | 即時: 撤回の完全執行＋無視されていた期間の明示的な記録と本人への開示。**撤回無視は不可侵条項（第1・2条）への違反として最重大級に扱う** |
| **報復**（T5） | 即時: 当事者の保護（支援の回復・関係の遮断は本人の選択で）。対象: 役割からの除斥（当該当事者への関与停止）。構造: 報復を可能にした情報流（誰が異議者を特定できたか）の監査 |
| **害悪の観測**（T6） | 接続の一時停止判断（人間が行う）。Phase 27 Bridge / care loop への advisory 接続。道義的レビュー記録の作成 |

### D8-7. 救済手段の比較と採用

| 手段 | 採否 | 理由・制約 |
|---|---|---|
| **謝罪** | 採用 | 本人が受け取りを望む場合のみ。公開謝罪の強制はしない（謝罪の儀式化・見世物化を防ぐ） |
| **修正**（記録訂正・状態回復） | 採用・最優先 | append-only の下での修正＝訂正記録の追加と違反状態の解消 |
| **停止**（機能・経路・関与の停止） | 採用 | 止める権限は分散・動かす権限は集中させない（Master Plan §4.3）。再開は交渉を要する |
| **再教育** | **限定採用** | 「再教育」は容易に儀式・見せしめになる。採用するのは役割固有の手続き理解の更新（例: 同意手続きの再確認）のみ。人格矯正的なものは行わない |
| **公開説明** | 採用 | 組織・構造レベルの帰属には公開説明責任を課す（D10-10 の公開層）。個人レベルは原則、限定公開（晒しを救済と呼ばない） |
| **金銭的補償** | **本 ADR では未決** | 実資金の移動は Treasury 境界（ADR-007 候補）の確定が前提。緊急の生活影響には既存の直接支援（§13.4）を優先適用し、「補償」制度の設計は ADR-007 後に追補する |
| **関係の修復（対話）** | 採用（任意） | 修復的対話は当事者の発意でのみ。制度が和解を演出しない |

### D8-8. 公開の三層（ADR-010 D10-10 の準用と拡張)

| 層 | 内容 |
|---|---|
| **公開** | レビューの件数・事由分布・帰属層の分布・応答の種類・所要期間（個人参照なし）。**構造帰属の結論と構造修正の内容は常に公開**（構造は晒されても傷つかない——構造は最大限公開する） |
| **限定公開** | 事案の経緯・個人の帰属（関与者と Panel、本人が望む場合 Dan-Go 交渉） |
| **非公開** | 当事者の身元・報復リスク評価・本人が非公開を望む一切 |

非対称原則の適用: **構造と権力には最大の公開、個人の失敗には抑制された公開、当事者には最大の保護。**

### D8-9. 再発防止の記録 — Accountability Memory

- すべてのレビューは append-only の **Accountability Memory** に記録される: 事由・事実確定・複合帰属・応答・構造修正・（あれば）不服と上訴の経過。
- 記録は「前例」として機能するが「判例法」として硬直させない——過去の帰属が将来の帰属を自動決定しない（事案はそれぞれの構造の中にある）。
- 構造修正の追跡: 「修正を約束した構造が実際に修正されたか」を監査人が期限つきで追跡し、未修正は新たなトリガー（T1 系）になる。**約束の不履行はそれ自体が事案である。**
- Relief Case Memory の系譜（「記録は支配ではない」）を継承する: Accountability Memory は関与者の永久烙印ではない。記録は消えないが、記録の**用途**は再発防止に限定され、関与者の将来の役割からの自動排除には使われない（自動排除はスコアリングの変種である——第4条）。

### D8-10. 責任制度自体への歯止め — 新しい権力にならないために

責任制度は最も正義の顔をした権力になりうる。よって:

1. **Panel は常設の地位ではない**——事案ごとに構成され、解散する（常設裁判所を作らない）。
2. Panel の決定も**異議の対象**である（ADR-010 の経路は Panel に対しても開いている——審査者を審査する経路の保証）。
3. 上訴先は Dan-Go 公開交渉であり、**最終審は Mujin の外にある**（Mujin が自分の責任の最終判定者にならない）。
4. レビューの**件数・帰属分布自体を構造指標として監視**する: 特定の層（例: 個人）への帰属が偏る場合、それは制度が身代わり装置化している兆候であり、制度自体のレビュー（本 ADR の改訂交渉）を発動する。
5. **Reach Gap への自覚**: 本制度に届く害悪は、異議経路に届いた害悪だけである。**届かない害悪——異議を出せない人が受けた害悪——は本制度の外に残り続ける**。本 ADR はこれを解決したと主張せず、レビュー記録の公開（D8-8）が「届かなかった人」の存在を推定する材料になることだけを期待する。

## Consequences

### 正
- ADR-010 の異議経路が「届いた先」を持ち、D10-7（報復の推定）が実効的な威嚇力を持つ。
- 第15条が宣言から手続きになり、claim-saiyan-scouter-001 論点10 への Mujin 側の応答が成立する（Dan-Go 全体への問いとしては残る）。
- 構造優先の帰属（D8-4）により、「個人を吊るして構造を守る」運用が困難になる。

### 負 / 要対応
- Panel 構成・Accountability Memory・追跡監査の**恒常運用コスト**が ADR-010 のコストに加算される。
- 金銭的補償の未決（D8-7）により、経済的害悪への応答が当面「直接支援の優先適用」という間接形に留まる。
- 当事者代表の参加（D8-3）は、当事者に新たな負担（レビューへの関与労力・心理的負荷）を生みうる——不参加の自由は保証したが、参加した場合の支援（翻訳・伴走・補償）の設計は ADR-010 の経路運用と同じ課題を持つ。

## Non-decisions
- 金銭的補償の制度設計（ADR-007: Treasury Boundary 確定後の追補事項）。
- Panel 構成員の報酬・任期の細目（Treasury と運用開始時の交渉事項）。
- 法的責任との接続（法域確定（MQ-19）後。本 ADR は道義的レビューが法的手続きを**妨げない**ことのみ確認する——当事者の法的救済の権利は本制度の外で完全に保持される）。
- Dan-Go 側の責任（claim-saiyan-scouter-001 論点10 は「Dan-Go 全体に問われるべき問い」とする——Mujin の本 ADR は Dan-Go の応答を代行しない）。

## Relationship to ADR-001〜006, 010
- **ADR-001**: T6 トリガーは正典 Reality Feedback の `requires_human_review` を道義的レビューの入口として具体化。整合。
- **ADR-002**: 上訴先を Dan-Go 公開交渉に置くが、これはデータ境界ではなく規範の経路であり疎結合を破らない。整合。
- **ADR-003**: 同意延期中の接触（T3）は昇格ゲートの違反として本手続きに接続。整合。
- **ADR-004**: 救済が支援の債務化（「償いの支援」）にならないよう、補償と支援を分離（D8-7）。整合。
- **ADR-005**: D-4 の運用化。D-10（非帰属）を運営側に対称適用（D8-1/D8-4）。整合。
- **ADR-006**: 不可侵条項への違反（撤回無視等）を最重大級に位置づけ（D8-6）。Panel 決定への異議保証は不可侵条項（異議権）の帰結。整合。
- **ADR-010**: 入口（トリガー T1–T5）と公開三層を共有。**依存: 本 ADR は ADR-010 の経路なしに起動できず、ADR-010 は本 ADR なしに空洞である**（自己レビュー④参照）。

---

*本 ADR は制度設計であり、実装・コードを含まない。本 ADR 自身が当事者参加経路の保証つき Dan-Go 交渉に服する。届かない害悪は本制度の外に残り続ける——Reach Gap は未解決であり、本 ADR はその解決を主張しない。*
