> 結論先取り: **失敗は「量の不足（Discovery/Participation/Consent ゼロ）」ではない。失敗は Relief Failure——なお救われていない者（Reach Gap）を放置し、保留のコストを当事者へ転嫁し続け、observation only を恒久的美徳として静かに当事者を忘却すること。最大の失敗は“騒がしい指標失敗（見える zero）”でなく、“注意深さを装った放置（静かな道徳的失敗）”である。Consent 不在そのものは失敗でない（正しい状態）が、Gateway を孤立させたまま動ける所で動かないことは、いま現に可能な失敗である。**

## 0. 失敗の問いは成功の鏡——そして最も危険な失敗は静かである

- F-6: 成功＝救済能力（量でない）。∴ 失敗も対称——**量の不足は失敗でない。**
- 二つの失敗族:
  - **Metric Failure（指標失敗）:** count が低い（discovery 0・participation 0・consent 0）。**見えるが、誤った物差し。real failure でない。**
  - **Relief Failure（救済失敗）:** 救われていない者を放置・転嫁・忘却する。**見えにくいが、real failure。**
- **最も危険なのは“静かな失敗”:** observation only を美徳として恒久化し、当事者が黙ってコストを払い、Dan-Go は自制に満足している状態。**騒がしい zero より、righteous な放置の方が致命的。**

## 1. Q1〜Q10 の監査

### Q1. Discovery 0 は失敗か

**No。** Discovery count は growth 指標（F-6 Q1）。ゼロは失敗でなく、せいぜい「門がほぼ開いていない」（F-1.7）の徴候。
- 失敗になるのは、**門が閉じたまま、当事者を待たせ、動ける所でも動かない時。** discovery 0 自体は失敗でない。

### Q2. Participation 0 は失敗か

**No。** 活動量であって救済でない（F-6 Q2）。参加ゼロは失敗でない。

### Q3. Consent 0 は失敗か

**No（H2）。** owner 不在ゆえ consent 0 は**正しい状態**（H-15/H-16）。
- むしろ **consent を“増やすために製造”すれば、それが失敗**（強制・dark pattern）。consent 不在を尊重することは成功の条件であって失敗でない。

### Q4. Reach Gap が残ることは失敗か

**存在は失敗でない。放置は失敗である（H3）。**
- Reach Gap（救えるのに救われていない者）の**存在**は、Dan-Go が立ち向かう問題そのもの——Dan-Go 以前から在り、Dan-Go の現容量を超える。**ギャップが在ること自体は Dan-Go の道徳的失敗でない。**
- だが Reach Gap を**忘却・容認・直視回避**し、動ける所で動かないことは失敗。
- **境界: 「ギャップを閉じきれていない」≠失敗（容量限界）。「ギャップから目を逸らす」＝失敗（放置）。**

### Q5. 保留が長期化することは失敗か

**保留それ自体は失敗でない。保留がアリバイ化した時に失敗になる。**
- consent 待ちの保留は正当（H-16 Q9・person 領域は consent 不可侵）。
- だが保留が (a) 動ける領域（gateway/findability）の不作為の口実になり、(b) コストを当事者へ黙って転嫁する時、**失敗に転じる**。
- **境界: consent 待ちの保留＝正当。動ける所を捨てた恒久保留＝失敗。**

### Q6. Observation Only が恒久化することは失敗か

**Yes（H4）。** Observation only は person 領域の正しい**床**（H-16）だが、Dan-Go 全体の恒久的**天井**になれば——観察だけして gateway/findability を放置——**静寂主義（abdication）の失敗**。
- 「観察した」を達成と勘違いした時点で失敗（H-16 §4：observation only が達成に見え始めたら失敗の徴候）。

### Q7. Findability が存在しないことは失敗か

**Yes——consent 経路の foreclosure（封鎖）として。**
- Findability は consent infrastructure（F-5）——不在 owner が**自ら見つけ consent する唯一の尊重的経路**。findability が無ければ、その門が構造的に閉じ、**consent opportunity が永久に開かない**。
- ただし「findability **count** が低い」（growth）ではなく「**門が構造的に閉じている**」（F-1.7: Mujin ほぼ発見不可）が失敗。質的な門の不在であって、量の不足でない。

### Q8. Gateway が孤立することは失敗か

**Yes——いま現に可能な、最も具体的な失敗。**
- Gateway（voice-006/JAR）は **consenting actor**で、Dan-Go が**正当に動ける領域**（供給側調整・Case D/E：協力者が互いを見つけられない・gateway が調整されない）に居る。
- gateway を孤立させたまま、**動けるのに動かない**ことは、唯一開いている領域での救済放棄。
- **これは person 領域の consent 待ち（正当な保留）と違い、gateway consent が在る領域での不作為——アリバイの効かない失敗。**

### Q9. Failure を count 化すると Saiyan Scouter を再発させるか

**Yes（F-6 Q9 と対称）。** 「失敗 count を**最小化**せよ」は選抜圧を生む。
- 失敗数を下げるため、**難しい・見えにくい・救いにくいケースを避ける**（救えなさそうな当事者を引き受けない）、または**失敗を隠す**。
- 前者は Saiyan Scouter（hard case 回避）、後者は虚偽（Reality Correction 違反）。
- **∴ 失敗も count 最小化の対象にしない。** 失敗は隠す/避ける対象でなく、直視・学習する対象。

### Q10. Dan-Go が最も避けるべき失敗は何か

**保留のコストを当事者へ転嫁し続け、当事者を忘却すること——注意深さを装った放置（H5）。**
- 最悪は騒がしい指標失敗（見える zero）でなく、**静かな道徳的失敗**: observation only を恒久的美徳とし、当事者が黙ってコストを払い、Dan-Go が自制に満足する状態。
- これが最も危険なのは、**不可視で、しかも righteous に感じられる**から——失敗だと気づかれない失敗。
- **避けるべき最大の失敗 ＝ 救われていない者を「外部・容認・忘却」し、動ける所で動かず、その放置を caution と呼ぶこと。**

## 2. 中心監査: Metric Failure vs Relief Failure

| 事象 | 族 | real failure か | 理由 |
|---|---|---|---|
| Discovery 0 | Metric | **No** | growth 指標（F-6） |
| Participation 0 | Metric | **No** | 活動量 |

## 3. 静かな失敗（Q10 の深化）

```
[observation only]  person 領域の正しい床（H-16）
   │  美徳としての恒久化・「自制した」への安住
   ▼
[静かな放置]  当事者が黙ってコストを払う・Dan-Go は righteous
   ▼
[最大の失敗]  救われていない者を caution の名の下に忘却
```

- 騒がしい失敗（見える zero）は気づける。**静かな失敗は気づけない——しかも善く感じられる。**
- **構造的保証: 「自制したか」でなく「保留のコストを誰が払っているか」を常に問う。** observation only が心地よくなったら、それを失敗の徴候として自己監査する。

## 4. 失敗 ≠ 容量限界（honest な較正）

- すべてを今すぐ救えないことは、それ自体では失敗でない——現容量を超える場合があり、不可能な基準を課すべきでない。
- **失敗は“結果”だけでなく“態度・行為”に宿る:** 忘却する・装う・放置する・アリバイ化する・隠す。
- **正直な基準: 容量の限界で救えないこと（直視し、動ける所で動いている限り）≠失敗。直視を止め、動ける所で動かないこと＝失敗。** これにより、道徳的真剣さを保ちつつ不可能基準を回避する。

---

## 5. 虚偽は失敗（Jammy House/D.R.A. の教訓）

- 「失敗に見えないため」に救済を**捏造・誇張**すること（実在しない支援を実在と表示）は、それ自体が失敗——しかも Reality Correction の中核違反。
- Q9 と連動: 失敗 count 最小化の圧は、隠蔽・誇張へ滑る。**失敗を正直に記録することは成功の条件であり、失敗を隠すことが二重の失敗。**
