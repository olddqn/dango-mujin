# Voice Candidate Verification Report

- **Status:** 検証報告（順位なし・スコアなし・推薦なし）。新機能・新 ADR・新レイヤなし。
- **Date:** 2026-06-13
- **対象:** [`docs/FIRST_CASE_CANDIDATES.md`](FIRST_CASE_CANDIDATES.md) の C1–C7
- **方法:** 公開された支援要請／救援活動／寄付要請／教育支援要請／難民支援要請の Web 確認のみ。

> **確認したのは次の3点だけ:** (1) Voice が実在するか (2) 現在も公開されているか (3) 接続可能な公開窓口があるか。
> **やっていないこと:** 個人の探索／SNS からの個人特定／推測／順位付け／スコアリング／推薦／「誰を助けるか」の決定。
> すべて**組織・公開アピールのレベル**。個人は一切含まない。

## 検証で言えること・言えないこと（重要）

- ✅ 言える: その公開要請が実在し、現在も公開され、公開の接続窓口（寄付・ボランティア等）がある。
- ❌ 言えない: その組織が Mujin との連携を受け入れるか／Mujin が接続すべきか／どれを選ぶべきか。**それは人間の判断であり、各組織への確認が別途必要。**
- これらはすべて**大規模・公的な公開アピール**であり、§3 の「既存の公開要請・稼働チャネルを経由する（個人に接触しない）」安全形に合致する。

## まとめ（事実のみ）

- **C1–C7 すべてについて、3点（実在・現在も公開・接続可能な公開窓口）が確認できた。**
- いずれも大規模・公的な公開アピール／常設プログラムであり、個人への接触を伴わない。
- C3・C4 は常設の運営プログラム（日付つきアピールではない）。C1・C5・C6 は2026年版の年次アピール。C2 は進行中のアピール（英赤十字は2026年末まで）。C7 は進行中のキャンペーン。

## この報告の限界（隠さない）

- **検証したのは「公開要請の実在・公開状態・公開窓口」のみ。** 連携の可否・適切さ・選定は含まない。
- **私の確認も最終ではない。** 実際に Voice として記録し Gateway 化する前に、人間が現行ページを再確認すること（Reality Correction: 現実 > デモの便宜）。
- **載っていない声がある。** これらは「公開された大規模アピール」であり、公開窓口を持たない・公開できない最も孤立した声は、この確認の射程外。それが Reach Gap の中心であることは変わらない。
- **順位・スコア・推薦はない。** どれを最初の一件にするかは人間の判断であり、選定理由も人間が記録する。
