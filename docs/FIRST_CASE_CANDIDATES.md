## 読み方（重要）

- **順序は意味を持たない。** 下記は地域・類型名のアルファベット/五十音順に並べてあり、優先順位ではない。
- **全候補が安全ゲートを通る前提で並べてある**（§3 第1段階: 公開出典あり／本人への直接接触不要／失敗時安全）。ゲートを通れない最も困窮した声は、ここに**載っていない**——それが Reach Gap の中心であることを忘れない（§X-0 §10）。
- 各候補は既存機能にこう対応する: **Voice = その公開要請** / **Gateway = それに応える実在の運営組織（要検証）** / **Contribution = その組織への協力** / **Reality Feedback = 組織または観察者の記録**。
- **「出典」欄は確認すべき情報源の種類・組織の慣用ドメインの目安**であり、確定 URL ではない。Reviewer が現行の公開要請ページを確認すること。

各候補の記録項目（§3・X-0 準拠）:
出典 / 公開性 / 同意到達性 / 実在Gateway接続可能性 / Reach Gap 検証価値 / TTFR 検証価値

## 候補一覧（C1–C7・順不同）

### C1. アフガニスタンの教育支援要請（特に女子教育）
- **出典:** 国際教育系・人道系団体の公開アピール（例として確認すべき種類: UNICEF、Norwegian Refugee Council 等の公開教育アピール／公的報道）。**確定 URL は要確認。**
- **公開性:** 高（公的機関・報道で広く公開）。
- **同意到達性:** 個人へは接触しない。既存運営組織の既存の同意関係を経由。本人同意が取れない段階では Need は `deferred`・非公開。
- **実在Gateway接続可能性:** 大規模運営組織が存在しうる。**稼働・受け入れ可否は要検証。**
- **Reach Gap 検証価値:** 高（教育資源は世界に存在するが構造的・制度的に届いていない典型）。
- **TTFR 検証価値:** 中（教材・翻訳・遠隔教育など接続→記録は可能だが、現地状況により feedback 取得が制約される）。

### C2. ガザの人道救援要請（戦災）
- **出典:** 大規模人道機関の公開緊急アピール（確認すべき種類: ICRC、UNICEF、MSF、UNRWA、WFP 等の公開アピール／公的報道）。**確定 URL・現行状況は要確認。**
- **公開性:** 高（国際的に公開）。
- **同意到達性:** 個人接触は禁止・不可能。既存の稼働支援チャネルを経由するのみ。
- **実在Gateway接続可能性:** 大規模国際機関が存在しうる。**現地アクセス・資金到達性は要検証。**
- **Reach Gap 検証価値:** 非常に高（資源は国際的に存在するが、アクセス・政治・封鎖で届かない＝Reach Gap の極端例）。
- **TTFR 検証価値:** 低〜中（接続＝既存チャネルへの協力は可能だが、現地からの本人/現地 feedback は安全に得にくい。代理 feedback で loop closed に留まる可能性）。

### C3. 国内（日本）生活困窮・食料支援要請
- **出典:** 公開されているフードバンク・子ども食堂ネットワーク等の支援要請（確認すべき例: Second Harvest Japan、地域の子ども食堂ネットワーク等の公開募集）。**確定 URL・受け入れ可否は要確認。**
- **公開性:** 高（公開募集）。
- **同意到達性:** 高（既存の地域団体が既に当事者との同意関係を持つ場合が多い）。Mujin は個人に接触しない。
- **実在Gateway接続可能性:** 高（実在の地域運営団体が存在しうる）。**稼働・連携意思は要検証。**
- **Reach Gap 検証価値:** 中（国内に食料資源はあるが分配で届かない）。
- **TTFR 検証価値:** 高（接続→協力→記録が安全に一周しやすい。本人/団体 feedback が比較的得やすい）。

### C4. 国内（日本）の難民・避難民の言語/法的支援要請
- **出典:** 難民支援団体の公開支援要請（確認すべき例: Japan Association for Refugees 等の公開募集／公的報道）。**確定 URL・受け入れ可否は要確認。**
- **公開性:** 高（公開募集）。
- **同意到達性:** 中〜高（既存団体の同意関係を経由）。個人接触なし。
- **実在Gateway接続可能性:** 中〜高（実在の支援団体が存在しうる）。**要検証。**
- **Reach Gap 検証価値:** 高（翻訳・法的支援の担い手は存在するが、言語・制度障壁で届かない＝Mujin の Translation/Legal Gateway の検証に直結）。
- **TTFR 検証価値:** 中〜高（翻訳協力など接続→記録が比較的安全に成立しうる）。

### C5. スーダン人道危機の救援要請（戦災・大規模・資金不足）
- **出典:** 大規模人道機関の公開アピール（確認すべき種類: UNHCR、WFP、ICRC 等の公開緊急アピール／公的報道）。**確定 URL・現行状況は要確認。**
- **公開性:** 高（国際的に公開、ただし報道露出は相対的に低い）。
- **同意到達性:** 個人接触は禁止。既存チャネル経由のみ。
- **実在Gateway接続可能性:** 大規模機関が存在しうる。**要検証。**
- **Reach Gap 検証価値:** 非常に高（「世界に資源はあるのに、注目・資金が届いていない」＝救える資源と未到達の乖離が大きい典型）。
- **TTFR 検証価値:** 低〜中（接続は可能、現地 feedback は制約。代理 feedback 中心になりうる）。

### C6. ウクライナの避難民・人道救援要請（戦災・避難）
- **出典:** 大規模人道機関・避難民支援の公開アピール（確認すべき種類: UNHCR、ICRC、UNICEF 等の公開アピール／公的報道）。**確定 URL・現行状況は要確認。**
- **公開性:** 高（国際的に公開）。
- **同意到達性:** 個人接触は禁止。既存チャネル経由のみ。
- **実在Gateway接続可能性:** 大規模機関・避難先国の支援団体が存在しうる。**要検証。**
- **Reach Gap 検証価値:** 高（避難民支援の資源はあるが、言語・移動・制度で届きにくい層が残る）。
- **TTFR 検証価値:** 中（避難先での翻訳・住居・教育の接続→記録は条件次第で成立しうる）。

### C7. 公開された教育支援要請（低所得/避難背景の若者の就学・学習）
- **出典:** 教育系 NGO・奨学/学習支援の公開募集（確認すべき種類: 実在の教育支援団体の公開募集／公的報道）。**確定 URL・受け入れ可否は要確認。**
- **公開性:** 高（公開募集）。
- **同意到達性:** 中〜高（既存団体経由）。個人接触なし。
- **実在Gateway接続可能性:** 中〜高（実在の教育支援団体が存在しうる）。**要検証。**
- **Reach Gap 検証価値:** 中〜高（学習機会・教材・指導者は存在するが、経済・言語・情報で届かない）。
- **TTFR 検証価値:** 中〜高（教材・翻訳・遠隔学習・メンタリング等の接続→記録が比較的安全）。

## この一覧の限界（隠さない）

- **すべて未検証。** どれ一つも、私が「稼働中・検証済み」と断定したものはない。Gateway 化の前に人間が出典と稼働状況を確認すること（Jammy House の教訓）。
- **私の知識はカットオフ（2026-01）があり、現行の公開要請・URL・組織状況は変わっている可能性がある。** 必要なら次のステップとして、各候補の現行公開要請を Web で確認して URL を確定できる（ご指示があれば実施）。
- **載っていない声がある。** 安全ゲート（本人直接接触なし・公開出典・失敗時安全）を通れない、最も孤立した・最も困窮した声は、この一覧に**現れない**。それが Reach Gap の中心であり、本一覧はそれを解決しない。
- **順位・スコア・推薦はない。** どれを選ぶかは人間の判断であり、選定理由（なぜそれを最初にしたか）も人間が記録すべき。

## 次にやること（既存機能のみ）

1. 人間が上記から1件を選ぶ（順位ではなく判断として。理由を残す）。
2. 選んだ候補の**現行の公開要請 URL と運営組織の稼働状況を確認**する。
3. 確認できたら、その公開要請を `/voice-submit` に Voice として記録（出典 URL・原文・Reviewer 実名）。
4. 運営組織を `/gateways` に登録（**稼働・未検証の別を正直に notes に明記**）。
5. 以降は [`FIRST_REAL_CASE_PROTOCOL.md`](FIRST_REAL_CASE_PROTOCOL.md) §5 の手順に従う。
