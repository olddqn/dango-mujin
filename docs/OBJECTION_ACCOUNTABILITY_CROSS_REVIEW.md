# Cross Review Report — 異議・責任・記憶の三制度統合レビュー

- **Status:** レビュー報告のみ。ADR の変更・新 ADR の作成・実装を含まない。
- **Date:** 2026-06-13
- **対象:** ADR-010（Non-Technical Objection Path Operations）/ ADR-008（Moral Accountability Procedure）/ ADR-011（Accountability Memory）
- **方法:** 三本を単一制度として読み、各 ADR の自己レビューが**単体視点では見えなかった結合問題**を抽出する。

---

## 0. 制度全体としての目的

三本は独立した ADR ではない。**「聞かれる権利・応答される権利・忘れられない権利」の三段からなる単一制度**である:

```
ADR-010  受理   — 異議が届く        （聞かれる権利）
ADR-008  手続き — 異議に応答がある  （応答される権利）
ADR-011  記憶   — 応答が消えない    （約束が忘れられない権利）
```

制度全体の目的は一行で言える: **権力側（Mujin・NPO・支援者・Agent 運用）の行動を、当事者の声によって、時間に耐える形で問い続けられるようにすること。** これは憲法第10〜12条（異議）・第15条（道義的責任）・第29条（当事者参加）の運用基盤であり、不可侵条項（ADR-006 D6-7）の実効性の全量がこの三本に懸かっている。

三本の設計品質は個別には高い。**問題は結合部と総量に現れる。**以下、観点別に指摘する。

---

## 1. 責任の空白（制度を貫通して残る穴）

### 1-1. 執行の空白（最大の貫通穴）
三本のどこにも**強制執行力がない**。010 の監査は握り潰しを「検出」し、008 の Panel は帰属を「記述」し、011 は不履行を「記録」する——しかし応じない対象に何かを**させる**力は、公開の恥と Dan-Go 上訴しかない。各 ADR は単体でこれを自認しているが、結合して見ると深刻さが増す: **三段すべてが同じ一つの賭け（恥が機能する共同体であること）の上に積まれている。** 賭けが外れる相手には、三本まとめて無力である。多段化は冗長性ではない——同一の単一障害点の三回繰り返しである。

### 1-2. 即時対応の空白
D8-6 は「即時: 公開停止・接触停止」等を定めるが、Panel は事案ごとに構成される（D8-3）。**Panel 成立前の緊急措置を誰が発動するのか**が三本のどこにも書かれていない。Master Plan §4.3 の緊急停止権（運営者）はあるが、運営者自身が対象の事案では使えない。撤回無視（T4）のような継続中の侵害は、Panel 構成を待つ間も進行する。**受理（010）と手続き（008）の間に、時間の穴がある。**

### 1-3. 制度自身が害悪源になった場合の空白
レビュー手続きそのものによる再外傷化・Panel の誤り・Memory の誤公開——**制度が生んだ害悪は誰がレビューするのか**。D8-10-2 は「Panel への異議も可能」とするが、その異議の Panel は同じ監査人プールから構成される。D11-10-3 のメタ記録は検出材料を残すだけ。**自己審査の禁止（D8-3 が運営を除外した理由）が、制度自身には適用されていない。**

### 1-4. Dan-Go 側の不在
最終審を Dan-Go 公開交渉に置く（D8-3・D8-10-3）が、**Dan-Go は受審義務を引き受けていない**。Dan-Go の交渉が上訴を扱わない・扱えない（参加者不足・関心の偏り）場合、最終審は構造的に空席である。次節 §8 で詳述。

## 2. 権力集中（結合して初めて見える集中）

三本を重ねると、意図に反して**新しい専門職階級**が形成されつつある。各 ADR は権力分散を個別に設計したが、分散先が同じ少数の役割に繰り返し指名されている。

### 2-1. 監査人への集中（最重要）
横断集計すると、独立監査人に以下が積み上がっている:

| 由来 | 監査人の権能 |
|---|---|
| D10-5 | 受理番号の全数突合・対応期限の監査・Dan-Go への監査報告 |
| D8-3 | Accountability Panel の**事実確定の主導** |
| D8-9 | 構造修正の期限つき追跡 |
| D11-6 | 休眠記録の**再活性の承認** |
| D11-7 | 公開前の**抽象化レビュー**（何が公開されるかの実質的決定） |
| D11-5 | 小標本抑制の運用 |

検出者・裁定主導者・記憶の門番・公開の編集者が**同一系統**に集まった。これは三権分離ではなく、**司法・検察・公文書館・報道局の兼任**である。監査人が取り込まれた場合（ADR-008 自己レビュー①-4 は Steward の取り込みのみ想定していた）、三本の制度は同時に沈黙する。ADR-011 自己レビュー②-4 がこの傾向を初めて指摘したが、**指摘止まりで設計的応答がない。**

### 2-2. Steward への集中と、010 自身の分離原則の侵食
ADR-010 は受理（Steward）と記録（Recorder）を分離した（D10-3）——受理者が単独で異議を消せないために。ところが ADR-008 D8-3 は「受理経路の継続性のため」Steward を Panel に入れた。**受理と裁定が同一人物の中で部分的に再結合している。** 除斥規則（Steward 自身が対象の場合）はあるが、「Steward が受理段階で形成した心証が裁定に持ち込まれる」構造的問題は除斥では消えない。010 が自ら立てた分離原則を、008 が善意（継続性）で侵食した——**単体では見えない、結合部の自己矛盾である。**

### 2-3. 集中の根本原因
原因は明確である: **三本が要求する人的役割の総数が、想定される運用規模の人員供給を超えている。** Steward・Recorder・監査人・Panel 当事者代表・翻訳者・（将来）Memory 管理——独立性要件を厳密に守ると最低でも常時5〜7名の非兼任人員が要る。立ち上げ期にこれは非現実であり、現実は兼任に流れ、兼任は集中になる。**三本のどれも、この算術を正面から書いていない。**

## 3. 当事者の負担（制度が被害者に課す労働）

単体では各 ADR とも当事者保護を厚く設計している。結合すると別の像が現れる: **害を受けた当事者が、制度の全段で働かされている。**

- 010: 異議を出す（経路を知り、受理番号を保持し、状態を照会する）。
- 008: Panel に参加する（または不参加により「事実が対象側の語りで確定する」圧力を受ける——ADR-008 自己レビュー②-4）。
- 011: 自身を推定しうる記述の秘匿強化を「要求できる」（D11-6）——つまり**公開記述を監視する仕事が当事者に渡っている**。

三段を通すと、当事者は数ヶ月〜年単位の手続きに伴走することになる。**最も精巧な権利の体系は、最も持久力のある当事者だけが完走できる**——これは自己申請バイアス（R1）の再帰であり、制度自身が批判している構造の再生産である。「不参加の自由」「記録されない権利」は各所にあるが、**完走支援（伴走者・補償・心理的ケア）は三本とも Non-decision に置いたままである。**

## 4. Reach Gap への影響

三本とも個別に誠実な不主張（「届かない害悪は外に残る」）を明記している。結合視点で加わる問題が二つ:

1. **資源の吸引**: 三本の恒常コスト（多言語電話・Panel・追跡監査・抽象化レビュー）は、Mujin の運用予算の相当部分を吸う。**制度に届いた人への応答の精緻化が、届いていない人へ向かうはずの資源と競合する。** 異議制度の充実が Reach Gap を—解決しないだけでなく—**間接的に拡大する**可能性は、三本のどこにも書かれていない。
2. **リテラシー勾配の再生産**: 受理番号・三層公開・休眠・再活性・訂正追記——制度の全機能を使いこなすには制度リテラシーが要る。非技術経路は「入口」の障壁を下げたが、**制度の深部（上訴・記録監視・再活性異議）は依然として読み書きと持久力の世界である。** 入口の平等と全行程の平等は別物である。

## 5. 10年運用時の破綻点（時系列予測)

| 時期 | 破綻シナリオ | 由来 |
|---|---|---|
| 1〜2年目 | **ブートストラップの未完**: 010 の暫定運用→三点一体採択（008 自己レビュー⑤の順序）が、Dan-Go 交渉の停滞で完了せず、制度全体が「Proposed のまま運用」で固定化する。正統性が永続的に仮設のままになる | ADR-006 D6-9 との循環 |
| 2〜4年目 | **コストの先行**: 三本の恒常費は Phase C から発生するが、Treasury 統治（ADR-007）は Phase E。**資金規律が確立する前に、最も重い恒常支出が走り始める**——三本は ADR-007 より先に必要（各自己レビュー⑤）だが、先行は財政的に無防備でもある | 順序のジレンマ |
| 3〜5年目 | **人員の枯渇**: 兼任禁止規則と人員供給の算術矛盾（§2-3）が表面化。独立性要件の「例外運用」が始まり、例外が常態化する（RA-8 の典型経路） | 三本共通 |
| 5〜7年目 | **記憶の地層化**: Memory が訂正追記とメタ記録で専門家にしか読めなくなる（011 自己レビュー②-3）。「公開されているが誰も読まない」状態で透明性が形骸化 | ADR-011 |
| 7〜10年目 | **儀式化の完成**: 受理は機能し、Panel は開かれ、記録は残る——しかし構造修正の履行率が静かに低下し、追跡監査が「未履行 n 件」を毎年公開するだけの装置になる。**制度は動いているが、何も変えていない** | 執行の空白（§1-1）の長期形 |

最も確率が高いのは3〜5年目の人員枯渇である。**三本の制度設計は、設計の精緻さに比して、それを担う人間の供給・持続・ケアの設計が一桁薄い。**（Steward の燃え尽きへの言及が 010 自己レビューに一行あるのみ。）

## 6. Dan-Go との境界

### 6-1. 一方的な役割指名
三本は Dan-Go に「最終審」「監査報告の受領者」「Steward/監査人の指名機関」「採択交渉の場」という役割を割り当てた。**しかし Dan-Go はこれを引き受けると合意していない。** ADR-002 の疎結合は「Mujin は Dan-Go のデータを読み、feedback を返す」という対称的な契約だった。三本が作ったのは非対称な依存——Mujin の正統性供給・紛争解決・人事をすべて Dan-Go に外注する構造——である。これは:

- Dan-Go 側の負荷として現れる(交渉は無償の人間の時間である)。
- Dan-Go が応じない場合、§1-4 の空白になる。
- **「Dan-Go への Claim として提起すべき事項」である**(ADR-006 D6-4 の規則を三本自身に適用すると、この役割指名は Mujin 側の ADR に書くだけでは足りない)。

### 6-2. データ境界は維持されている（良好な点）
異議記録・Panel 記録・Memory はすべて Mujin 側（`bridge/mujin/` 系統）に閉じ、Dan-Go の Execution Log・正典への書き込みはない。異議→事案の一方向リンク設計（D11-4）も境界衛生として適切。**規範の境界は侵食気味だが、データの境界は無傷である。**

## 8. 総合所見と推奨（提案のみ・未適用）

### 制度としての評価
**設計思想は一貫して高品質である。** 「処罰ではなく直視」「構造から先に問う」「権力に透明・弱さに保護」「消えるのではなく休眠する記録」——三本を貫く原則は Dan-Go/Mujin の思想系譜に忠実であり、相互参照も概ね正確。単体の完成度で言えば採択に耐える。

**しかし制度としては、結合部に4つの未解決を抱える:**

1. **執行の空白**（§1-1）と**緊急措置の空白**（§1-2）——賭けの一本化。
2. **監査人の事実上の超役割化**（§2-1）と **010 の分離原則の 008 による侵食**（§2-2）。
3. **人的供給の算術**（§2-3）——精緻な分離要件と現実の人員の矛盾。
4. **Dan-Go への一方的役割指名**（§6-1）——最終審の空席リスク。

### 推奨（採択交渉の前に）
- 監査人系統の**機能分割**（検出監査 / 裁定主導 / 記憶管理を別人格に）を、人的算術（§2-3）と同時に検討する——分割が人員的に不可能なら、**どの集中を受け入れるかを明示的に選び、記録する**（暗黙の集中が最悪である）。
- D8-3 の Steward の Panel 参加を再検討する（受理と裁定の再結合、§2-2）。
- 緊急措置の発動者（Panel 成立前）を定める追補。
- 「Dan-Go に最終審を委ねる」ことを **Dan-Go への正式な Claim として提起**する（Mujin 側 ADR の記載だけでは成立しない）。
- 当事者の完走支援（伴走・補償・ケア）を Non-decision から引き上げ、ADR-007 の設計項目に明示的に積む。
- 第4条 vs 当事者保護の衝突（§7）を、採択交渉の独立論点として付議する。

### 最後に
三本の制度は「届いた声に誠実であること」を最高水準で設計した。**残る最大の問いは、三本の外にある: 声が届くことと、声に応えられることと、応え続けられることは、すべて人と資金の供給の関数である。** 制度は設計できた。制度を生かす身体の設計——人員・資金・ケア——が、ADR-007 以降の本体である。
